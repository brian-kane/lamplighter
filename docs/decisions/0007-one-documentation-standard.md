# 0007: One documentation standard in every repo I work in

Status: Accepted

Date: 2026-10-16

## Decision

- The issue says why the change is needed and what done means.
- The commit body says why this diff exists.
- The PR says how the commits form a reviewable unit, how it was checked, and what was not checked.
- One home per fact; link instead of repeating.

## Reason

Each fact is written once, in the place a reader will look.

## Alternatives rejected

- Restating the same rationale in issue, commit and PR.

## Revisit trigger

Reviewers repeatedly miss information because of where it lives.
