# 0008: GitHub Issues for personal projects

Status: Accepted

Date: 2026-10-16

## Decision

Personal issue tracking lives in GitHub Issues from the ground up.

## Reason

Decisions and tickets kept outside git were lost in earlier repos; Issues link directly to commits and PRs.

## Alternatives rejected

- An external board (kept only as an archive).

## Revisit trigger

Planning across several repos outgrows per-repo Issues.
